# 19. 页面重设计（管理后台 + C 端）

> 文档编号：19
> 上级：[需求与开发规范总纲](./README.md)
> 关联：06~13（功能需求来源）、16（原系统对照）
> 决策：**需求按本文档重新确定，页面全部推翻重做**（2026-10-21 用户确认）。
> 视觉方向：医疗健康绿 **#00A870** 为主色的企业级克制风格。

## 1. 目标与范围

- **范围**：管理后台 `xfjk-web`（全量 15 个页面）与 C 端 `xfjk-app`（uniapp，现有 4 页扩展为完整页面集）全部重做。
- **不在范围**：后端接口形态不变（沿用文档 06~13 定义的接口清单）；仅页面结构、交互、视觉重做。
- **推翻重做 ≠ 新造功能**：功能点以 06~13 文档为准，本文档只定义**页面如何承载这些功能**。

## 2. 设计规范（强制，全端统一）

### 2.1 设计令牌

| 类别 | 值 |
|---|---|
| 品牌主色 | `#00A870`（主按钮 / 选中态 / 链接 / 关键数据，禁止满屏铺） |
| 主色浅底 | `#e6f7f1`（选中背景、tag 浅色） |
| 文字 | 标题 `#1f2329` / 正文 `#4e5969` / 次要 `#86909c` / 禁用 `#c9cdd4` |
| 边框 | 常规 `#e5e6eb` / 浅分割 `#f2f3f5` |
| 背景 | 页面底 `#f5f7fa` / 卡片 `#ffffff` / 表头 `#fafafa` / hover 行 `#f7f8fa` |
| 状态色 | 成功 `#00b42a` / 警告 `#ff7d00` / 危险 `#f53f3f` |
| 间距 | 8px 基准，仅用 4/8/12/16/24/32；卡片内边距 16~24 |
| 字号 | 12 辅助 / 13 表格正文 / 16 卡片标题 / 20 页面标题 |
| 圆角 | 组件 4px / 卡片 8px；阴影极轻 `0 1px 2px rgba(0,0,0,.03)` |
| 字体 | `-apple-system,"Segoe UI","PingFang SC","Microsoft YaHei",sans-serif` |

### 2.2 页面骨架规则（两端通用）

- 灰底白卡分层；一个页面**只有一个视觉重点**；所有左边缘严格对齐。
- 主色只出现在：主按钮、选中态、链接、关键数据；一排禁止多个实心主色按钮。
- 列表页固定骨架：筛选卡片 → 表格卡片（左标题右主操作）→ 分页右对齐。
- 危险操作必须二次确认；表单校验错误显示在字段下方。
- 交付前按 `admin-ui-design` skill 自检清单逐条过。

## 5. 验收标准

1. 两端所有页面按本文档骨架与令牌实现，无硬编码色值/间距（令牌文件之外）。
2. 页面访问链路完整：登录 → 首页 → 各功能页可互相跳转。
3. 后台经流水线部署后 `8181` 可访问；小程序 HBuilderX/CLI 编译通过。
4. 视觉自检截图逐条过 skill 自检清单，无"一排实心按钮 / 元素紧贴 / 素颜纯白"问题。
5. in-DOM 模板自定义标签显式闭合（无构建页面）。

## 6. 约束与禁止

- 禁止引入新 UI 框架/构建流程（后台仍为无构建静态页；小程序不新增重型插件）。
- 禁止改动后端代码与接口定义（占位数据仅用于页面预览）。
- 禁止硬编码颜色/间距/字号，一律引用令牌变量。
- in-DOM 模板禁止自闭合标签。
