# 18. 调研来源分级与口径登记

> 文档编号：18
> 上级：[需求与开发规范总纲](./README.md)
> 关联：01、04、06~13、20
> 模块：无（本文档是需求侧的**口径单一来源**，不产出代码）
> 地位：**06~13 与 20 的字段级规格必须引用本文档的口径 ID**，不得自拟口径。

## 1. 本文档的用途与用法

### 1.1 为什么存在
v2.x 的 `18` 只有 7 个来源（体检平台宣传页 + 后台脚手架），只能论证「要不要有这个模块」，给不出「这个字段怎么校验、这个状态怎么流转、这个分值怎么算」。结果：06~13 写不细不是笔力问题，而是**没有口径源**，实现时全靠拍板。

本文档改为提供**可直接实现的业务口径**：每条口径带唯一 ID、权威出处、落点（哪份文档哪一节）。实现任何字段、状态、算法、阈值前，先在 §3 找到自己的口径 ID；§3 里没有的，一律回到 §5 登记为待确认，不得自行发明。

### 1.2 来源权威分级
| 级别 | 类型 | 效力 | 用法 |
|---|---|---|---|
| **L1** | 国家标准、卫生行业标准、部颁规范、学会标准 | 强制/推荐性文件 | 可直接作为验收判据；实现不得偏离 |
| **L2** | 公立医院体检系统政府采购功能参数公告 | 招标要求的实际业务条款 | 作为功能完整性对照与验收条目来源 |
| **L3** | 三甲医院体检中心现行体检须知、分检/总检实操记录、检验审核规范 | 一线操作口径 | 作为校验规则、异常处理、差错防范来源 |
| **L4** | 体检管理系统（PEIS）与健康管理 SaaS 厂商公开功能说明 | 行业成熟实现 | 作为模块划分与交互流程参考，**不作为口径依据** |
| **L5** | 体检预约平台宣传页、后台脚手架 | 信息架构参考 | 仅用于流程与页面结构启发 |

**冲突处置**：L1 > L2 > L3 > L4 > L5。同级冲突时取更新时间更晚者，并在 §5 登记。

### 1.3 调研方法
- 按 L1→L5 逐层检索，L1/L2/L3 为重点（能给出可执行口径），L4/L5 仅用于对照模块划分。
- 每条口径必须能指向具体条款或表单，不接受「某某系统也有这个功能」式的论证。
- 与项目自带原型（`manage/` Axure 后台原型、`weixin/` C 端 H5 原型）和原库表结构逐项对照，标出现状差距。
- 本目录需求的所有新增口径均来自本节方法，不复制任何产品的代码或私有实现。

## 6. 结论

1. 本目录需求的功能模块、字段清单、状态流转、算法阈值与校验规则，均可指向 §2 的具体来源与 §3 的口径 ID，**需求有据、可核、可实现**。
2. v2.x 需求文档「写不细」的根因已由本文档消除：此前缺乏 L1/L2/L3 级口径源，导致 06~13 只能写「做什么」而无法写「按什么值做」。
3. **本期范围变更已由 D-26 正式关闭**：企业团检从「不做」移入本期，边界限定为四级模型 + 名单 + 分组 + 备单 + 团体报告，不含费用结算。
4. 「本期实现 / 明确不做 / 后续版本」三类边界已分别列于 §5.1、§5.2、§5.3，与 `01` §2.3/§2.5 一致，无冲突。
5. 所有口径变更（含阈值调整）**只允许改 §3 本表**，并同步在 `17` 留痕；下游文档不得自行复述阈值。

## 7. 约束与禁止

- **禁止无源口径**：`06~13` 与 `20` 中出现的任何阈值、状态枚举、判定规则、字段值域，必须能引用到 §3 的口径 ID；引用不到的一律先登记进 §5.2 或 `17` 待确认，不得直接写进功能文档。
- **禁止复述阈值**：功能文档只写「按 A10 判定」，不得把 `总分>160` 这类数值再抄一遍，避免两处不一致。
- **禁止把 L4/L5 当依据**：厂商功能页与平台宣传页只能启发模块划分与交互流程；作为验收判据的口径必须来自 L1/L2/L3。
- **禁止凭记忆补标准**：涉及 WS 系列、ZYYXH/T157、国家基本公卫规范的字段与数值，须以本文档登记的条款为准；需扩充字段清单时，先取回标准原文核对，再写入 §3，不得按印象填写数据元。
- **禁止改动冻结表以承载新口径**：8 张原库表禁止 `ALTER`/加列/加索引（见 `08` §7、`07` §8）；所有新增字段走 `t_health_*` 扩展表（1:1 关联，按 `04`），一号制等只能在应用层实现。
- **禁止医疗结论自动化免责**：量表得分、异常判定、结论合并均为**辅助**，最终医学结论由总检医师负责；系统不得输出「已确诊」类表述，界面与报告文案须体现「建议进一步检查/就诊」。
- **禁止收录可识别个体的调研数据**：本文档及其来源引用不得带入真实患者数据；测试数据须为构造数据并按 `14` 清理。
- 敏感字段（身份证、手机号）在展示与导出时须脱敏，遵循 `03` §6、`05` §7。
