### 1.1 追补决策（2026-10-22，基线追平）

下列事项**已经发生在代码里**，但当时未回写文档，导致 `01`/`02`/`03`/`13`/`15`/`16` 与代码互相矛盾。本节把事实追记为决策，使文档重新具备约束力。

| # | 事项 | 结论 | 理由 | 回滚代价 |
|---|---|---|---|---|
| 20 | **后端版本升级** | 底座 5.6.2 之上升级 **JDK 17→25**、**Spring Boot 3.5→4.1.1**（Spring Framework 7.0.9）、**Jackson 2→3**（`tools.jackson`）；依赖审计升级 **Lombok 1.18.48 / Hutool 5.8.48**；Sa-Token 1.46.0、MyBatis-Plus 3.5.17 | 学习型项目要求跟最新技术栈；提交 `1096921`（升级）与 `2b0ab37`（依赖审计） | **高**。回滚需降 JDK、退回 Jackson 2 并全量改回 `com.fasterxml` 导入，重跑 35 模块构建与测试。升级已验证：全模块编译 + 测试通过，`xfjk-admin` 可启动、`/auth/login` 端到端可用 |
| 21 | **后台前端形态** | 采用 `xfjk-web`：静态 HTML + Vue 2 + Element-UI 2（UMD vendored）+ axios 0.18.0 + echarts，**无 npm、无构建**；设计令牌走 `css/tokens.css` | 沿用原系统页面资产做视觉重做，改造成本远低于迁 SPA；`19` §3 已按此定义 15 个页面 | **中**。若要迁 plus-ui 等于 15 个页面全部重写，且需引入完整构建链与 CI |
| 22 | **C 端形态** | 采用 `xfjk-app`：uniapp 3 + Vue 3 + TS + vite，微信小程序 / H5 双端 | 需同时交付微信小程序与 H5，uni-app 一套代码双端；`19` §4 已按此定义 | **中**。改回纯 H5 则失去小程序端 |
| 23 | **接口加密开关** | `xfjk-admin/application.yml` 的 **`api-decrypt.enabled: false`**，仅限内网开发/测试（`192.168.20.130`） | 静态管理端无前端加密实现，开启时 `CryptoFilter` 对 `@ApiEncrypt` 接口（含 `/auth/login`）返回 403，登录链路不通 | **必须执行**：对外部署前恢复 `true` **并**交付前端加密实现，否则敏感接口明文。已列入 `15` §5.3 安全红线 |
| 24 | **前端网关代理** | `xfjk-web/nginx.conf` 在 `\.do$` 之外**新增 `location /auth/`** 反代到 `xfjk-admin:8080` | 后端登录/登出/验证码入口是 `/auth/**`，不以 `.do` 结尾，否则命中静态规则返回 404 | 低。删除该 location 即回退，但登录不可用 |
| 25 | **业务落地顺序** | 先追平文档基线，再打**一条垂直切片**：`08 预约管理 → 套餐管理`（建 `xfjk-health-appointment` 模块 + 套餐/检查组/检查项三表 + `/health/setmeal/**` + 改 `xfjk-web` 对应页接真接口），跑通后作为其余 5 个模块的样板 | `06`~`13` 的功能需求在业务模块与表为 0 的现状下不可直接执行，须先有可复制的打通范例 | 低。切片只新增模块与表，不改既有代码 |

> 决策 20 是 `02` §6 / `15` §2「不得擅自升降版本」铁律的**唯一已批准例外**。除该条所列范围，版本铁律继续有效。
