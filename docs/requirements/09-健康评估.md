# 09. 健康评估

> 文档编号：09
> 上级：[需求与开发规范总纲](./README.md)
> 关联：03、04、05、07、10、13、18
> 模块：`com.xinfei.health.assessment`

## 1. 用途
以**通用问卷引擎**为底座，承载标准量表（心理测评 SCL-90、中医体质辨识等）与自定义问卷；完成「发起评估 → 作答 → 计分 → 生成结论与建议 → 归入人群」的评估闭环，并管理指标库、评估建议与人群分类。

## 3. 问卷引擎设计

### 3.1 模型
```
问卷(questionnaire) 1─N 题目(question) 1─N 选项(option)
问卷 1─N 因子(scale_factor)        # 维度定义（如 SCL-90 九因子）
问卷 1─N 评分规则(scale_rule)      # 因子/总分 → 等级与结论
问卷 1─N 建议(suggestion)          # 按因子/等级给出建议文本
```
- **题型**：单选、多选、填空、量表（Likert）。跳题由 `jump_rule` 控制。
- **计分**：`scoring_type` 决定算法（见 §3.2）；选项 `score` 累加；多选取权重或求和（按规则）。
- **发布状态**：仅「发布」的问卷可用于 C 端作答；编辑已发布问卷需新版本（`version` 递增，保留历史记录一致性）。

### 3.2 计分算法（`scoring_type`）
| 类型 | 算法 |
|---|---|
| `sum` | 总分 = 各题得分之和 |
| `factor` | 按 `factor_code` 聚合各因子分；因子分 = 因子内题目得分之和（或均值，按系数） |
| `scale` | 通用量表：同时产出总分与因子分，并据 `scale_rule` 定级 |

## 4. 内置标准量表

### 4.1 SCL-90（症状自评量表，心理测评）
- 90 题，1~5 计分（没有/很轻/中等/偏重/严重）。
- **9 因子**：躯体化、强迫症状、人际关系敏感、抑郁、焦虑、敌对、恐怖、偏执、精神病性（另有 7 个附加项）。
- 产出：总分、总均分、阳性项目数、因子分（各因子均分）。
- 常用筛查阈值（**可配置，默认参考量表通用口径**）：总分 ≥ 160、阳性项目数 > 43、任一因子分 > 2，提示需关注。
- 因子分/等级经 `scale_rule` 映射到结论与建议。

### 4.2 中医体质辨识（九种体质）
- 题量与题目按标准中医体质问卷录入（平和质、气虚质、阳虚质、阴虚质、痰湿质、湿热质、血瘀质、气郁质、特禀质）。
- 计分：按标准**转化分**公式（原始分 → 转化分）=（原始分 − 条目数）/ (条目数 × (量表级数−1) ) × 100。
- 判定：平和质与偏颇质的判定规则写入 `scale_rule`。

> 量表题目内容以**公开标准量表**为准，通过题库种子数据导入（不臆造）；引擎本身与具体量表解耦，可扩展更多量表。

### 4.3 风险测评（再议）
原原型「风险测评」暂不作为独立量表，归属为引擎下的**普通问卷**（`category=question`），后续可细化。

## 5. 指标管理 / 评估建议 / 人群分类
- **指标库**（`t_health_indicator`）：维护可评测指标（编码、单位、参考区间、类型），供报告与评估引用。
- **评估建议**（`t_health_suggestion`）：按「问卷/因子/等级」配置建议文案；评估完成后自动匹配，亦支持人工补充。
- **人群分类**（`t_health_crowd` + `t_health_crowd_rule`）：以因子/指标条件（≥/≤/区间/等于 + 逻辑与或）定义人群；评估完成后按规则自动归入（`t_health_member_crowd`），供干预与统计使用。

## 7. 评估流程（提交作答）
1. 校验问卷已发布、题目完整（未答题按规则处理，缺答返回 `7002`）。
2. 按 `scoring_type` 计分，写入 `assessment_answer`、`assessment_factor`、`assessment_record`（总分/阳性数/结论/等级）。
3. 依据 `scale_rule` 生成结论与等级；依据 `suggestion` 匹配建议。
4. 依据 `crowd_rule` 计算所属人群，写 `t_health_member_crowd`。
5. 事务提交，返回结果。

## 8. 页面（后台）
问卷设置、题库管理、心理测评（SCL-90）配置、中医体质辨识配置、指标管理、评估建议、人群分类、评估记录列表/详情。

## 9. 验收
1. 问卷/题目/选项 CRUD 生效；发布后 C 端可见，草稿不可见。
2. SCL-90 作答后总分、阳性项目数、9 因子分计算正确；等级与建议匹配正确。
3. 中医体质作答后转化分与体质判定正确。
4. 评估记录、因子分、建议完整落库并可查询。
5. 人群规则命中后会员正确归入对应人群；干预模块可读取（见 `10`）。
6. 缺答/无效作答返回 7002；未发布问卷返回 7001。

## 10. 约束与禁止
- **量表题目与计分**必须来自**公开标准量表**的种子数据，**禁止臆造**题目、选项、因子或阈值（见 `15` §0.3）。
- 计分与分级规则必须**可配置**（`scale_rule`/`scoring_type`），**禁止**把阈值/因子硬编码进代码。
- 已发布问卷的编辑须 `version` 递增，**禁止**改动导致历史评估记录不可复现。
- 提交作答写操作必须**同一事务**；缺答/无效按 `7002` 处理，禁止部分落库。
- 人群归类须可追溯（记 `source_record_id`），禁止无来源地写入 `t_health_member_crowd`。
- C 端仅返回**本人**评估；公开问卷接口不得泄露其他会员数据。
