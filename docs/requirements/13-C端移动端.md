# 13. C 端移动端

> 文档编号：13
> 上级：[需求与开发规范总纲](./README.md)
> 关联：03、05、07、08、09、10、11
> 形态：**Vue3 + Vant（H5）**，独立前端工程。

## 1. 用途
会员移动端：预约体检、查询报告、健康评估、查看干预计划、健康档案、健康资讯、登录。

## 4. 交互规则
- 请求统一走 Axios 封装；返回统一 `R`；未登录统一跳登录页。
- 下单前顺序：**日期校验 → 验证码校验 → 提交**。
- 登录成功后保存 Sa-Token 下发的 C 端 token，请求自动带 `Authorization: Bearer <token>`。
- 需登录页面：档案、报告、订单详情、评估历史、干预方案；公开页面：套餐、资讯、验证码、问卷查看与提交（提交需登录，见 `09`）。
- 所有"本人数据"接口按 token 中 `memberId` 过滤，越权返回 403（见 `05` §5）。

## 5. 验收
1. 首页 6 入口跳转正确。
2. 套餐列表/详情（三级结构）展示正确。
3. 验证码登录可用；下单全流程可完成并返回订单号；订单详情可查。
4. 健康档案、报告（含明细与附件）、评估（作答→结果/建议）、干预计划均可查看本人数据。
5. 资讯列表/详情正常展示。
6. 越权访问他人数据返回 403；未登录访问需登录页跳登录。

## 6. 约束与禁止
- C 端为**独立工程**（Vue3 + Vant），禁止混入 plus-ui 代码或原 jQuery/独立 HTML 页面。
- 所有"本人数据"接口**必须按 token 中 `memberId` 过滤**，禁止信任前端传入的 `memberId`（防水平越权）。
- 请求**统一走 Axios 封装**（自动带 token、统一 401/403 处理），禁止散落裸 Axios/fetch。
- 下单顺序固定为 **日期校验 → 验证码校验 → 提交**，禁止跳步或前端"假校验"替代后端校验。
- 禁止硬编码接口域名、密钥、AppId；走环境配置。
- 公开接口禁止返回他人数据或敏感字段（身份证/手机号须脱敏）。
